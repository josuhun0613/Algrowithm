## 각 섹션 상세

### 1. 아키타입 카드

```
┌─────────────────────────┐
│                         │
│  🔥                     │
│                         │
│  잠든 전략가              │
│  The Dormant Strategist │
│                         │
│  실행력 엔진은 풀가동인데  │
│  내비게이션이 꺼져 있는    │
│  상태. 목적지만 찍히면     │
│  누구보다 빠르게 도착할    │
│  사람.                   │
│                         │
└─────────────────────────┘
```

**AI 생성 요소:**
- 아키타입 이름 (한글 + 영문)
- 이모지 1개
- 설명 3~4줄 (비유적, 인스타 공유 욕구 자극)

**아키타입 풀 (AI가 조합에서 선택/생성):**
```
잠든 전략가 / 방향 없는 로켓 / 완벽주의 탐험가
숨은 연결가 / 조용한 혁신가 / 자유로운 분석가
멈춘 실행가 / 고민하는 창조자 / 안정 속의 모험가
```

### 2. 커리어 좌표 (Position Map)

Recharts 기반 2축 산점도:

```
      방향성 (clarity)
        ↑
   100 │
       │    ★ 목표 지점
    75 │
       │
    50 │        ● 현재 위치
       │
    25 │
       │
     0 ├────────────────→ 실행력 (action)
       0   25   50   75   100
```

**축 정의:**
- X축 (실행력): 모듈 C 강점 + 모듈 A 패턴에서 계산
- Y축 (방향성): 모듈 A 이슈 + 모듈 B 가치관에서 계산
- 현재 위치: 실제 점수
- 목표 지점: AI가 추천하는 이상 좌표

### 이미지 저장
- html2canvas로 대시보드 상단 영역 캡처
