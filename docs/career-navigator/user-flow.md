## 전체 플로우 요약

```
진입 ──→ 모듈 A ──→ 모듈 B ──→ 모듈 C ──→ (모듈 D) ──→ 대시보드
 30초     90초      60초      60초      120초(선택)    즉시
                                                    ──────
                                              총 3.5~5.5분
```

## 진입 화면 (`/` 또는 `/booth/[id]`)

### 시나리오 1: QR 스캔 (서서)
```
QR 스캔 → 브라우저 열림 → 진입 화면
```

### 시나리오 2: 상담사 안내 (앉아서)
```
상담사가 URL 직접 입력 또는 태블릿 전달
```

### 진입 화면 구성

```
┌─────────────────────────┐
│                         │
│                         │
│   Algrowithm            │
│   Career Navigator      │
│                         │
│   AI가 당신의 커리어를    │
│   읽어드립니다            │
│                         │
│                         │
│  이름을 알려주세요        │
│  ┌─────────────────┐    │
│  │ 홍길동            │    │  ← 유일한 텍스트 입력
│  └─────────────────┘    │
│                         │
│                         │
│  [🚀 커리어 스캔 시작]   │  ← 풀코스 (A→B→C→결과)
│                         │
│  [🔍 심층 분석만 하기]   │  ← 5-Why만 (상담사용)
│                         │
│                         │
│  ─ 또는 ─               │
│                         │
│  [📋 이전 결과 보기]     │  ← slug 입력으로 재방문
│                         │
└─────────────────────────┘
```

### 진입 모드 3가지

| 모드 | 경로 | 모듈 | 대상 |
|------|------|------|------|
| 풀코스 | A → B → C → (D) → 결과 | 전체 | 부스 착석자 |
| 심층 분석 | D → 결과 | 5-Why만 | 상담사 판단 |
| 재방문 | 결과 페이지 직행 | 없음 | 공유 링크 클릭 |

## 모듈 간 전환

### 페이지 전환 방식
- Framer Motion `AnimatePresence` + `layoutId`
- 카드가 슬라이드되듯 자연스럽게 다음 질문으로
- 토스 스타일: **한 화면에 하나의 질문**만

### 전환 트리거
- 카드 탭 (선택) → 0.3초 애니메이션 → 다음 질문
- 자동 진행 (선택하면 자동으로 넘어감, "다음" 버튼 없음)
- 뒤로가기 가능 (상단 좌측 ← 버튼)

### 진행 표시
```
상단 고정:
━━━━━━━━━━●━━━━━━━━━━━━━  모듈 A: 3/6
```
- 토스 블루(#3182f6) 프로그레스 바
- 현재 모듈 내 위치만 표시 (전체 모듈 수는 안 보여줌 → 부담 감소)

## 모듈 완료 → 분석 → 대시보드

### 분석 요청 타이밍
- 모듈 C 완료 시 (5-Why 스킵인 경우) → 즉시 분석
- 모듈 D 완료 시 (풀코스인 경우) → 즉시 분석

### 분석 로딩 화면 (`/analyzing`)
```
┌─────────────────────────┐
│                         │
│                         │
│                         │
│                         │
│   홍길동님의 커리어를     │
│   분석하고 있어요         │
│                         │
│                         │
│   ████████████░░░ 78%   │
│                         │
│   커리어 좌표를           │
│   계산하는 중...          │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
```

로딩 메시지 순차 표시 (3~8초):
```
"답변을 분석하는 중..."
"커리어 좌표를 계산하는 중..."
"가치관 DNA를 해독하는 중..."
"숨겨진 강점을 발견하는 중..."
"내비게이션 경로를 계산하는 중..."
```

### 대시보드 진입
- 분석 완료 → 자동으로 `/result/[slug]`로 이동
- slug 예시: `홍길동-20260308`
- 이미 같은 slug가 있으면: `홍길동-20260308-2`

## 대시보드 이후 플로우

```
대시보드 확인
    │
    ├── [📸 이미지 저장] → html2canvas → 갤러리 저장
    │
    ├── [📱 카카오 공유] → 카카오 SDK → 링크 전달
    │
    ├── [🔗 링크 복사] → 클립보드 복사
    │
    ├── [🔒 잠금 해제] → /unlock → 코드 입력 → 상세 리포트
    │
    └── [세미나 알아보기] → 외부 링크 (신청 폼)
```

## 상담사 운영 플로우

```
상담사 시점:

1. 참석자 착석
2. 태블릿에서 / 접속 → 이름 입력
3. "커리어 스캔 시작" 탭
4. 참석자에게 태블릿 전달
5. 참석자가 A→B→C 진행 (상담사는 옆에서 관찰)
6. 결과 나오면 함께 보면서 대화
7. "더 깊이 가볼까요?" → 모듈 D 시작 (상담사 판단)
8. 최종 대시보드 → 세미나 안내

상담사가 할 수 있는 것:
- 모듈 스킵 (각 모듈 완료 후 "다음 모듈로" 또는 "바로 결과 보기")
- 5-Why 시작/스킵
- 세미나 코드 직접 입력 (잠금 해제)
```

## 에러/이탈 처리

| 상황 | 처리 |
|------|------|
| 중간에 브라우저 닫음 | Zustand persist로 로컬 저장, 재접속 시 이어하기 제안 |
| AI 분석 실패 | Gemini Flash로 폴백 → 그래도 실패 시 "다시 시도" 버튼 |
| 네트워크 끊김 | 오프라인 감지 → "연결을 확인해주세요" 토스트 |
| 같은 이름+날짜 중복 | slug에 -2, -3 자동 부여 |
