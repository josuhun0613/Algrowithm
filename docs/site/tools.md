## 1. AI 이미지 스튜디오 (`image-studio.html`, 약 1,481줄)

### 목적

워크북 사진을 업로드하면 AI가 캐릭터 일러스트를 생성

### 2가지 모드 (탭 토글)

| 모드 | 설명 |
|------|------|
| **프롬프트 입력** | 직접 영어 프롬프트 입력 → 이미지 생성 |
| **워크지 업로드** | 워크북 사진 업로드 → Gemini 분석 → 프롬프트 자동 생성 → 이미지 생성 |

### 워크지 업로드 플로우

1. **캐릭터 스타일 선택** (6개 카드, 체크박스 오버레이):
   - Minion (미니언즈), Chibi (치비/SD), Anime (애니메이션)
   - Pixar/Disney (픽사/디즈니), Webtoon (웹툰), Minimal (미니멀)

2. **캐릭터 형태 선택**: human / animal / fantasy / robot

3. **배경 타입 선택**: transparent / gradient / themed

4. **워크북 이미지 업로드**: 드래그앤드롭 존 + file input (최대 4장)

5. **Gemini 분석**: `/api/analyze.js` (mode: 'character') 호출
   - 워크지에서 캐릭터 정보 추출
   - 스타일 옵션 반영된 영어 프롬프트 자동 생성

6. **이미지 생성**: `/api/generate-image.js` 호출 (Imagen 4)
   - 비율 선택: 1:1, 3:4, 4:3, 9:16, 16:9

7. **결과**: 이미지 표시 + 다운로드/복사/재생성 버튼

### 인증

- 접근 코드 입력 → 서버 환경변수 키 사용
- 또는 사용자 직접 API 키 입력

## 2. 웹사이트 스튜디오 (`website-studio.html`, 약 2,414줄)

### 목적

AI와 대화하며 웹사이트를 실시간으로 만드는 Lovable 스타일 빌더

### 레이아웃

```
┌─────────────┬──────────────────────┐
│  채팅 패널   │    에디터/프리뷰      │
│  (420px)    │    (나머지 영역)       │
│             │  ┌─ 탭: Code | Preview │
│  메시지      │  │                    │
│  입력창      │  │  Monaco Editor     │
│  빠른 액션   │  │  또는 iframe       │
└─────────────┴──────────────────────┘
```

### 좌측 채팅 패널

- 다크 테마 (`#0f0f10`)
- 웹사이트 이름/설명 입력 필드
- AI/사용자 메시지 교대 표시
- 빠른 액션 버튼 (스타일 변경, 섹션 추가 등)
- textarea + 전송 버튼

### 우측 에디터/프리뷰

- **Code 탭**: Monaco Editor (HTML/CSS/JS 편집)
  - 테마: `vs-dark`
  - 자동 완성, 구문 강조
- **Preview 탭**: iframe에서 실시간 렌더링
- 하단: 다운로드, 배포 버튼

### API 연동

- `/api/generate-website.js`: Gemini에 메시지 + 현재 코드 컨텍스트 전송 → HTML/CSS/JS 코드 응답
- 접근 코드 필수 (`IMAGE_ACCESS_CODE` 동일)

### 배포 기능

- `/api/deploy-site.js`: 생성된 HTML을 Vercel에 배포
- 배포 URL: `algrowithm.org/sites/{name}`

## 3. E-book 프롬프트 생성기 (`ebook-generator.html`, 약 1,112줄)

### 목적

단계별 마법사로 E-book 생성 프롬프트를 만들어줌

### 단계 (Step Progress Indicator)

| 단계 | 내용 |
|------|------|
| 1 | 장르 선택 (자서전, 비즈니스, 소설, 에세이 등) — 카드 클릭 |
| 2 | 책 제목 입력 또는 AI 제안 |
| 3 | 목차/개요 입력 |
| 4 | 타겟 독자 설정 |
| 5 | 톤/스타일 선택 |
| 6 | 최종 프롬프트 생성 + 복사 |

### UI 컴포넌트

- 스텝 진행 표시: 번호 원형 + 연결선 (완료=gold, 현재=진행중, 미래=gray)
- 장르 카드: 클릭 시 선택 스타일 (gold 보더 + 체크)
- 결과 영역: 생성된 프롬프트 + "복사" 버튼
- 로딩: 스피너 + 토스트 알림
